# Triage labels

Record a `Readiness:` field on local tickets when triage applies. Keep the ticket's `Status:` for implementation progress.

| Label | Meaning |
| --- | --- |
| `needs-triage` | Requires evaluation |
| `needs-info` | Missing information |
| `ready-for-agent` | Fully specified for agent implementation |
| `ready-for-human` | Requires human implementation |
| `wontfix` | Will not be implemented |

Tickets produced from an agreed spec are already specified; do not send them through triage again.
