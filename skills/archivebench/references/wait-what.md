# Wait, what? Explain the plan

Bundled from the user's `wait-what` skill so this guidance works without a separate skill installation:

> Wait, I don't understand where you've got to here. Re-pitch that: give me a little bit of context, talk in ASD-STE100 Simplified Technical English, and use the ubiquitous language from `GLOSSARY.md` (follow `GLOSSARY-MAP.md` to the right one if the repo has more than one).

Apply this to the pre-benchmark brief: state the purpose first, use short direct sentences, define unfamiliar terms, and use the repository glossary when present. Explain what the user will get and what they must judge. Use the tables required by [comparisons](comparisons.md). This is communication guidance, not a claim of formal ASD-STE100 compliance.
